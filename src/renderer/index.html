    Your camera stays yours

    • Everything runs on this computer. The pose model ships inside the app. No account, no server.
    • Works with no internet. The app blocks every network request and its security policy forbids connections outside itself — you can pull the cable and it behaves the same.
    • No pictures or video are stored. Each camera frame is analysed in memory and thrown away. Only a handful of numbers (head height, shoulder width, tilt) survive, and only your calibration baseline is saved to disk.
    • The camera is only on when needed — while monitoring, calibrating or running the live setup check. Pause monitoring and the camera light goes off.
    • Verify it: the app is open source; npm test and the README explain how to confirm there is no network or storage code path for images.
